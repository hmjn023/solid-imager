# Danbooru・pixiv Viewer

サイドバーの **Danbooru** から、ローカルに保存せず投稿を検索・閲覧できる。
Web と Tauri は同じ画面とサーバー側の API を使う。

- 検索欄では Danbooru のタグ式を使う。スペース区切りは AND、`-tag` は除外。
  `rating:g`、`order:score` などのメタタグもそのまま渡す。
- 入力中のタグを API で補完する。候補にはタグ種別と投稿数を表示する。
  別名からの候補取得にも対応し、選択時には正規名を入力する。
- 一覧ではライブラリと共通の検索バーとメディアグリッドを使う。検索欄には
  `/` で移動できる。サムネイルにフォーカスして矢印キーで移動し、Enter で詳細を開く。
  下端に近づくと次の投稿が自動で追加される。追加取得に失敗したときは、その位置で再試行できる。
- 詳細はライブラリと同じプレビューと情報パネルを使う。前後の投稿への移動や
  画像の拡大に対応し、「一覧に戻る」で検索結果のスクロール位置とフォーカスが戻る。
  `/danbooru/<投稿ID>` の直接アクセス・再読み込みにも対応する。
- 画像の「取り込み待ちへ」は既存の Import inbox に追加する。
  保存先の選択と実際の取り込みは Import inbox で行う。
  原本 URL がない投稿や、動画・ZIP など画像以外は取り込み対象にしない。
- Danbooru と pixiv をサイドバーで切り替えると、検索タグと入力中の文字列を引き継ぐ。
  検索先を変えると先頭から表示する。同じ一覧を再読み込みすると、見ていた投稿の位置から再開し、上にスクロールするとその前の投稿も読み込める。

## pixiv で同じタグを検索する

たとえば両方の画面で `hatsune_miku` を選べる。pixiv では Danbooru Wiki の
`other_names` から日本語表記を優先して検索し、実際の検索語を一覧の上に表示する。
候補欄で日本語の Wiki 別名から正式タグを探すこともできる。
別名は完全な同義語とは限らないので、候補が複数あればそこで選び直せる。
対応する別名がなければ入力タグをそのまま使う。

スペース区切りは AND、`-tag` は除外、複数の `~tag` は OR として変換する。
Danbooru 固有のメタタグやワイルドカードを pixiv へ送ろうとすると画面に理由を表示する。
空の検索欄ではデイリーランキングを開く。

Wiki が使えないときは公開の [Wiki 別名スナップショット](https://github.com/Jannchie/danbooru-tag-index/releases/tag/data-latest)
をサーバーで読み、最大 1 日キャッシュする。スナップショット由来の候補には投稿数・カテゴリがない。
作品詳細の URL は `/pixiv/<作品ID>`。複数ページの作品は表示中の原本を取り込み待ちに追加できる。
うごイラは再生時にサーバー上の FFmpeg で変換する。画像配信には pixiv の Referer を付ける。

## 任意の認証設定

未設定時は匿名アクセスする。検索タグ数や閲覧範囲には Danbooru 側の制限が適用される。
アカウントでアクセスする場合は、サーバーの環境変数を両方設定して再起動する。

```dotenv
DANBOORU_LOGIN=your-login
DANBOORU_API_KEY=your-api-key
```

公開作品はそのまま閲覧できる。自分の pixiv アカウントを使う手順は Web・Tauri 共通。

1. pixiv Viewer の「pixiv にログイン」を開き、公式 pixiv にブラウザーでログインする。
2. 同じブラウザーの xtracter 拡張で、接続先に自分の Solid Imager サーバー（HTTPS または localhost）を指定する。「Viewer の接続コードを発行」を押すと、そのサーバーに pixiv セッションが渡る。
3. Viewer にコードを貼り付けて「接続する」を押す。コードの有効期限は 5 分で、1 回だけ使用できる。
4. 接続中は Viewer に pixiv ID が表示される。ID を押すとログアウトできる。

拡張を使えない環境では「拡張機能を使わずに接続」から、自分のブラウザーの pixiv Cookie にある `PHPSESSID` の値を直接入力できる。

pixiv セッションはサーバーのメモリーに保持する。1アカウントにつき未使用の接続コードは8件、同時に接続できる Viewer は8件まで。接続枠が埋まった場合は、別のタブでログアウトすれば、有効期限内のコードで再試行できる。
Viewer の接続はタブ単位で最長 12 時間有効。サーバー再起動後は再接続する。旧設定 `PIXIV_PHPSESSID` を使っていた場合も、利用するタブで接続する。
ユーザーごとのアカウント切り替えや、お気に入り等のリモート更新は実装していない。

API 通信は `danbooru.donmai.us` 固定で、リクエスト開始間隔を 250ms 以上空ける。
同一リクエストを集約し、投稿は 30 秒、候補は 5 分キャッシュする。
閲覧するメディア URL は HTTPS の `donmai.us` とそのサブドメインに限定する。
メンテナンス・アクセス制限・接続失敗は画面上で再試行できる。

## 検証

`bun run check` と `bun run test` に加え、隔離環境で次を実行する。

```sh
bun run test:e2e danbooru.responsive.spec.ts pixiv.responsive.spec.ts
```

E2E は外部の検索・画像配信を固定データに差し替え、取り込み待ち登録は実 API と
隔離 DB で検証する。Danbooru 自体の稼働状況とは独立して回帰を検出できる。

API 仕様: [投稿](https://danbooru.donmai.us/wiki_pages/api%3Aposts)、
[タグ](https://danbooru.donmai.us/wiki_pages/api%3Atags)。
