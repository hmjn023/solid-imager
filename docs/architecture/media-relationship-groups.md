# 漫画・同時投稿・差分の関係グループ

Related: #818, #617

## モデル

`media_groups` と `media_group_members` を追加する。同時投稿 (`post`)、漫画 (`comic`)、差分 (`variant`) は独立したグループで、一枚は複数に所属できる。グループを特定の画像に従属させないため、一ページの削除では他の所属は失われない。既存の `media_relations` は派生画像等の有向関係用に維持する。

状態は所属ごとの `candidate` / `tentative` / `confirmed` / `rejected`。解除は `rejected` として残し、自動再取り込みで復活させない。由来 `source` / `manual` は判断状態とは独立する。順序は内部では0始まり、画面では1始まり。未確定順序はNULL。同順位はmedia IDで安定整列する。

## 取り込み

xtracterの任意項目 `sourcePost` はサービス、投稿ID、投稿内位置を運ぶ。Pixivはページ一覧の位置、Xは画像のpermalinkに含まれるphoto番号を利用する。旧拡張・JSON取り込みは認識できるX/Pixiv/FANBOXの投稿URLから投稿IDを復元する。投稿URLから位置を復元できない場合は推測しない。

`platform:postId` の一意キーと所属の複合主キーで、別バッチ・部分成功・再送を同じ投稿に集約する。取得済み画像のダウンロード省略時も所属を追加する。新しい情報で補うのは自動所属の未確定順序のみ。手動の状態・順序には触れない。投稿への所属が確認できても、漫画・差分という意味は自動確定しない。

## 操作

Web/Tauriのメディア詳細に共通編集画面を表示する。

- この画像を含む暫定グループを作成する。
- 既存グループから、却下以外の画像を引き継いで漫画・差分グループを作る。
- 名前で既存グループを検索し、現在の画像を暫定追加する。別投稿の続きを追加する場合も同じ操作。
- 各所属の状態・順番を明示的に保存する。却下済みの所属は編集・復元のために表示する。

RPC/REST: `mediaGroups.list`, `mediaGroups.create`, `mediaGroups.setMember`。共有Zod契約とOpenAPIを更新する。DB migration 0036は既存データを削除しない。

## 現段階の範囲

画像の類似度による差分候補検出、漫画リーダー、既存データ全体の自動バックフィルは含まない。既存画像は再取り込みまたは手動操作で紐づけられる。メディア単位のエクスポート・コピーにグループを引き継ぐ機能は未対応。DB全体のバックアップには追加テーブルも含める必要がある。

## 検証

PGliteで追加migration、順不同の取り込み、再送、手動判断の保持、ページ削除、作成失敗のrollbackを検証する。ダウンロード経路では新規登録と重複省略の両方を検証する。ブラウザーでは投稿からの漫画作成、保存失敗時の入力保持、状態と順番の保存、狭い画面での表示を検証する。
